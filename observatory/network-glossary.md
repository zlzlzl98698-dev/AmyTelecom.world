### # 与 A

#### AS4134 (ChinaNet / 电信 163 骨干网)
中国电信历史最悠久、覆盖面最广的民用骨干网。承载了国内绝大多数普通家庭宽带流量。由于国际出口总带宽常年超载，晚高峰（20:00-23:00）期国际关口局丢包率常高达 20%-40%，极易造成视频卡顿。

#### AS4809 (CN2 / CN2 GIA)
中国电信下一代承载网（China Telecom Next Generation Carrier Network）。其中 **GIA (Global Internet Access)** 代表最高等级的双向优化通道。拥有独立的国际出口关口局与极轻的轻载光纤，晚高峰丢包率通常低于 1%，采购单价高昂。

#### AS9929 (中国联通 A 网 / CUII)
原中国网通骨干网留存的政企专用顶级网络。网络负荷极低，晚高峰抗拥堵性能卓越，延迟稳定性比肩电信 CN2 GIA，常用于高端商业中转机场的跨境入口。

#### AS4837 (China169 联通民用骨干)
中国联通普通民用骨干网。由于联通早年国际出口冗余度较高，单向优化的 4837 线路在白天和非核心高峰期性价比极高，常见于第二梯队平价机场。

#### AS58453 (CMI / 中国移动国际)
中国移动国际骨干网。移动凭借巨大的海缆投资，在广州、香港之间拥有庞大的传输管道，常用于大带宽香港落地中继。

#### Anycast (任播技术)
一种网络寻址和路由技术。多个分布在全球各地的物理服务器共享同一个 IP 地址。客户端发起的请求会自动被底层 BGP 协议路由至物理距离最近或网络状况最好的单台服务器，广泛应用于 Cloudflare CDN 及大型 DNS 服务。

#### AEAD (关联数据的认证加密)
Authenticated Encryption with Associated Data。一种现代对称密码学加密标准（如 AES-256-GCM、ChaCha20-Poly1305）。在加密数据的同时生成一个 16 字节的认证标签（Auth Tag），彻底绝杀了防火墙针对传统流密码的“重放探测攻击”。

#### ACL4SSR
国内 GitHub 开源社区维护最广泛、知名度最高的代理智能分流规则集。通过维护海量域名与 IP 白名单，实现“国内直连、国外加速、流媒体分流、广告拦截”的精细化策略调度。

### B

#### BGP (边界网关协议)
Border Gateway Protocol。互联网核心自治系统（AS）之间的动态路由协议。在翻墙机场中，“BGP 入口”指机场在国内租用了支持三大运营商（电信/联通/移动）全网接入的机房，无论用户使用的是什么宽带，均能以最短的物理跳数接入机房，杜绝跨网延迟。

#### BBR (Bottleneck Bandwidth and RTT)
由 Google 研发并开源的全新 Linux 内核 TCP 拥塞控制算法。与传统基于“丢包即减半发送窗口”的 Cubic 算法不同，BBR 通过实时探测网络的最小往返时延（Min RTT）和最大瓶颈带宽（BtlBw），即便在存在公网丢包的环境下也能最大化跑满物理带宽。

---

### C

#### CWND (拥塞窗口)
Congestion Window。TCP 协议中由发送端动态控制的最大并发发送字节数。网络丢包会导致 CWND 急剧缩小，直接引发传输速度呈断崖式下跌。

#### Cloudflare Turnstile
Cloudflare 推出的新一代无感智能人机验证（CAPTCHA）系统。通过静默评估客户端的浏览器环境、TLS 握手特征与 IP 信誉分，自动决定是否放行访问，广泛应用于 OpenAI (ChatGPT) 与 Claude 的前置风控拦截。

---

### D

#### DPI (深度包检测)
Deep Packet Inspection。高级网络防火墙（如 GFW）采用的流量检测技术。除了检查数据包的源 IP、目的 IP 和端口（传统二/三层），还会深入重组并解析四层以上的数据载荷（Payload），利用统计学模型和协议特征指纹识别加密代理流量。

#### DoH / DoT (基于 HTTPS/TLS 的 DNS)
DNS over HTTPS (RFC 8484) 与 DNS over TLS (RFC 7858)。将传统的明文 UDP 53 端口 DNS 请求封装在加密信道中传输，彻底杜绝本地运营商在传输过程中的 DNS 劫持、窥探与投毒。

#### DNS 污染 (DNS Cache Poisoning)
国内防火墙针对境外受限域名（如 google.com）采取的阻断手段。在用户向境外 DNS 发起明文查询时，GFW 会在真实解析响应返回之前，抢先一步向用户伪造并下发一个错误的虚假 IP，导致浏览器无法连接真实目标。

#### DRM (数字版权管理)
Digital Rights Management。流媒体服务商（Netflix、Disney+、Apple TV+）用于保护其高品质视听版权作品的技术。移动设备上分为 Google Widevine L1（硬件级芯片解码，支持 4K HDR）与 L3（纯软件解码，强制锁定 720p/540p）。

---

### E 与 F

#### Fake-IP 模式
一种在 Clash (Mihomo) 与 OpenClash 中被广泛采用的革命性 DNS 处理模式。路由器在接收到域名解析请求时不向外发起真实查询，而是瞬间从私有保留池中分配一个虚拟 IP（如 `198.18.0.2`）返回给操作系统。真实解析工作完全推迟至境外落地节点执行，彻底解决 DNS 污染并实现 0ms 瞬间建连。

#### Full Cone NAT (NAT A / Type 1)
全锥形 NAT。NAT 穿越能力最高的一种网络状态。一旦内部端口映射到公网 IP 和端口，任何外部主机均可直接向该公网端口发送数据包。对于 PS5、Nintendo Switch 联机游戏而言，Full Cone 能够实现秒级组队匹配且永不掉线。

---

### G 与 H

#### GFW (国家级网络防火墙)
Great Firewall of China。对中国出入境互联网流量进行边界管控、IP 阻断、DNS 劫持、SNI 阻断以及主动探测（Active Probing）的国家级硬件软件综合防护系统。

#### Hysteria 2 (歇斯底里 2)
基于 UDP (魔改 QUIC 协议) 开发的新一代跨境代理工具。采用了独特的拥塞控制机制，在面对丢包率高达 20% 以上的恶劣公网链路时，能够通过暴力多倍发包和快速重传抢占带宽，是极度弱网环境下的绝杀利器。

---

### I

#### IPLC (国际私有租用线路)
International Private Leased Circuit。电信运营商提供的传统物理点对点租用光纤链路（通常基于 SDH/OTN 传输网）。属于二层时分复用链路，全程完全运行在封闭的运营商内部网络中，**物理上不经过公网国际关口局，因此绝对不可能被 GFW 拦截，丢包率稳定 0%**。

#### IEPL (国际以太网专线)
International Ethernet Private Line。新一代基于以太网标准的跨国专线服务。相较于传统 IPLC，IEPL 具有弹性扩容极快、协议支持更现代化、成本调优更灵活的优势。现代高品质商业机场（如 [光速云](/reviews/guangsu)）所采用的均为企业级 IEPL 专线。

#### ISP 住宅 IP vs IDC 机房 IP
- **ISP / Residential (住宅 IP)**：由当地电信运营商直接分配给普通家庭光纤宽带的真实 IP，信任度最高，是完美解锁 ChatGPT、Claude 与 Netflix 非自制剧的核心钥匙；
- **IDC / Hosting (机房 IP)**：属于云厂商数据中心（AWS、GCP、阿里云等）的服务器 IP，在风控数据库中信誉分极低，极易触发人机验证死循环与封禁。

### J 与 M

#### Jitter (网络时延抖动)
连续两个数据包往返时间（RTT）的差值或标准差。Jitter 越小代表网络越平顺。在线音视频会议、大模型流式打字与联机对战对抖动极度敏感。IEPL 专线通常将 Jitter 牢牢控制在 2ms 以内。

#### JA3 / JA4 (TLS 客户端指纹)
一种基于客户端在 TLS Client Hello 握手包中所包含的密码套件（Cipher Suites）、扩展列表（Extensions）和椭圆曲线等参数生成的 MD5 哈希指纹。防爬虫系统利用 JA3 能够瞬间识别发起的请求究竟是真实 Chrome 浏览器，还是 Python 脚本或代理工具。

#### Mihomo (原 Clash.Meta)
当代开源代理生态中最具统治力的高性能核心内核。基于原版 Clash 深度重构，原生支持 VLESS Reality、Hysteria 2、TUIC、WireGuard 等现代协议，并由活跃的开源社区持续维护，是 Clash Verge Rev 与 OpenClash 的底层引擎。

### N 与 O

#### OpenClash
运行在 OpenWrt 路由器固件上的顶级科学上网分流插件。利用 Mihomo 内核实现家庭全屋设备的透明代理、Fake-IP 智能分流与 DNS 防泄露。

#### On-Demand (按需连接)
iOS 平台（Shadowrocket / Loon / Surge）独有的电源优化机制。仅当系统有实际需要加速的出站网络请求时才瞬时唤醒 VPN 虚拟网卡，锁屏待机时自动休眠，能有效节省移动设备多达 15% 的电量。

---

### P 与 Q

#### Per-App Proxy (分应用代理)
Android 客户端（v2rayNG / FlClash）的核心功能。允许用户自主勾选仅加速特定应用程序（如 Chrome、YouTube、ChatGPT），让微信、支付宝、银行 APP 100% 走本地真实宽带直连。

#### QoS (服务质量流量整形)
Quality of Service。运营商骨干网路由器在带宽超载时执行的流量优先级队列调度策略（如 WRED 算法）。在晚高峰国际出口拥塞时，普通民用 163 流量会被优先丢弃，导致严重的网络卡顿。

---

### R

#### Reality (VLESS XTLS-Reality)
由 Xray 团队研发的革命性伪装技术。无需自备域名与申请 SSL 证书，直接借壳偷取知名权威站点（如 Apple、Microsoft）的 SNI 和证书握手。面对 GFW 的主动探测试探，Reality 会将握手透明转发给真实官方服务器，实现天衣无缝的伪装。

#### Redir-Host 模式
传统透明代理模式。路由器在拿到真实 DNS 解析结果后再匹配路由表。缺点是极易遭受本地 DNS 污染，且每次解析都需要等待完整的 DNS 往返时延。

---

### S

#### Shadowsocks (影梭)
由 clowwindy 于 2012 年开源的轻量对称加密代理协议。现代版本全面升级为 AEAD 认证加密（AES-256-GCM / ChaCha20）。虽然在公网直连中易受封锁，但在 **IEPL / IPLC 专线内网** 中凭借其极低的计算开销、极省电和零额外报头开销，依然是商业专线机场的核心首选。

#### ShortId
VLESS Reality 协议中用于客户端与服务端身份鉴权的一串 16 进制字符串。只有携带正确 ShortId 的握手包才会被 Reality 服务端认定为合法翻墙流量，非法探测包会被无缝重定向给目标官方网站。

---

### T

#### Trojan (特洛伊木马)
将自己 100% 模拟为标配 HTTPS 协议的翻墙方案。运行在 443 端口，配备合法的 CA 证书。当未携带认证密码的普通访客或 GFW 探针访问时，会自动回落展示真实的 Nginx 静态个人网站。

#### TUN 模式 (虚拟网卡模式)
通过操作系统内核级驱动（如 Windows 的 Wintun 或 Linux 的 tun 接口）创建一张虚拟网络适配器。直接接管全系统所有层级的所有 IP 数据包，无需应用程序主动配置 HTTP 代理。

---

### U 与 V

#### VLESS
一种轻量化的无状态代理协议。去除了传统 VMess 繁琐的动态 HMAC 认证头，将所有加密伪装职责全权交由外层的 TLS / Reality 负责，大幅降低了服务器内存占用与计算延迟。

#### VMess
V2Ray 项目早期的主力协议。由于报文首部在经过数年发展后被 GFW 深度机器学习模型精准提取了统计学特征，极易被防火墙识别并封锁，目前已属于被社区淘汰的技术。

---

### W 与 Z

#### WRED (加权早期随机检测)
Weighted Random Early Detection。运营商核心路由器在接口队列溢出时执行的硬件级主动丢包算法。根据流量的优先级（VIP 专线 vs 普通民用 163），成比例丢弃低优先级的数据包。

#### Zero-RTT (0 往返时延握手)
在 TLS 1.3 及现代代理协议中，客户端在向服务端发送第一个连接请求数据包的同时，直接携带应用层业务数据，将握手等待时间从过去的 2-3 个 RTT 压缩至 0 个 RTT，显著提升高频小数据包的交互响应速度。
