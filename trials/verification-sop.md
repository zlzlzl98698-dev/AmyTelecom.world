# 试用期用 MTR 压测验明真假专线 SOP：3 分钟测出真实丢包率与骨干网归属

<div class="hero-badge">工程实测专项 · AmyTelecom 实验室 2026 深度发布</div>

在拿到机场的试用订阅后，不要被测速软件上花哨的多线程跑分所蒙蔽。多线程测速只能代表瞬间突发带宽，无法反映网络在持续负载下的**抖动（Jitter）、物理丢包率（Packet Loss）与真实网络拓扑架构**。

**网络工程师最权威、最无法被商家造假作弊的诊断工具，正是 MTR (My Traceroute)。**

通过结合 Ping 与 Traceroute 的长周期连续发包探测，MTR 能以毫米级的精度清晰展现数据包从你家电脑出发、经过每一个路由器接口、穿过国境线直到境外落地机房的全路径体检报告。

本篇 SOP 手册手把手教你在 3 分钟内验明手头节点的真实成色。

## 1. 真假专线判别三大硬核判据 (Direct Answer)

| 检测核心指标 | 真正的高品质 IEPL / IPLC 专线 | 伪专线 (公网 163 直连 / 劣质中转) |
|---|---|---|
| **出境路由物理跳数** | **极短 (通常仅需 3 到 5 跳直达境外落地)** | 极长 (往往需要 12 到 20 跳在公网中漫游) |
| **中途公网关口局 IP** | **全程绝不出现 `202.97.x.x` (163 关口局)** | 频繁出现 `202.97` 并在该节点开始出现丢包 |
| **晚高峰 21:00 丢包率** | **严格锁定在 0.0% - 0.1%** | 飙升至 15% - 40% 甚至更高 |
| **往返时延抖动 (StDev)** | **极小 (< 2.0 ms，平直如镜)** | 极大 (> 30.0 ms，剧烈上下锯齿跳动) |

## 2. 三分钟实操实测步骤 SOP

```mermaid
flowchart LR
  Step1["步骤 1: 下载 WinMTR 绿色版<br>(macOS 在终端运行 brew install mtr)"] --> Step2["步骤 2: 提取节点中转入口域名或 IP<br>(在客户端节点详情中复制 Server 地址)"]
  Step2 --> Step3["步骤 3: 在晚高峰 21:00 启动连续发包<br>(设置发包间隔 1s，连续发送 200 个数据包)"]
  Step3 --> Step4["步骤 4: 对照判据分析 Loss% 与跳数<br>真假专线瞬间无所遁形！"]
```

### 关键数据列解读：
1. **Host**：经过的每一个物理路由器 IP。第一跳通常是你家本地 Wi-Fi 路由器（如 `192.168.1.1`）；
2. **Loss % (丢包率)**：**最核心指标！** 从第二跳到最后一跳，真正的专线必须保持全绿 **`0.0%`**；
3. **Avg (平均时延)**：从国内入口到出境落地，如果时延仅递增了 5-15ms（如深港陆缆物理传播耗时），说明是真正的物理直连专线；
4. **StDev (标准差/抖动)**：代表网络的波动幅度。StDev 小于 2ms 代表极其平稳，适合打游戏、跨国高频会议和大语言模型持续打字输出。
